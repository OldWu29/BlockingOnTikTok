# 抖音一键拉黑（BlockingOnTikTok）

一款适用于 **Microsoft Edge / Chrome** 等 Chromium 内核浏览器的扩展，让你在 [抖音网页版](https://www.douyin.com) 刷视频时，**一键拉黑或解除拉黑当前视频作者**，并在本地管理黑名单。

> 本项目与抖音（字节跳动）**无任何官方关联**，仅为提升网页浏览体验的第三方工具。

---

## 功能特性

| 功能 | 说明 |
|------|------|
| 一键拉黑 | 识别当前正在播放的视频作者，调用抖音官方接口完成拉黑 |
| 一键解除拉黑 | 对已拉黑作者快速取消拉黑 |
| 悬浮按钮 | 在抖音页面右下角显示操作按钮，随作者状态自动切换文案 |
| 扩展弹窗 | 查看当前作者信息，执行拉黑 / 解除拉黑 |
| 黑名单管理 | 查看、搜索、批量管理本地拉黑记录 |
| 快捷键 | `Ctrl+Shift+B` 拉黑，`Ctrl+Shift+U` 解除拉黑 |

---

## 适用场景

- 推荐流刷到不感兴趣、营销感强的作者，想立刻屏蔽
- 不想反复走「点头像 → 菜单 → 拉黑 → 确认」的官方流程
- 需要集中查看、搜索、解除已拉黑用户

## 安装方法

### 方式一：开发者模式加载（推荐）

1. 克隆或下载本项目到本地
2. 打开浏览器扩展管理页
   - Edge：`edge://extensions/`
   - Chrome：`chrome://extensions/`
3. 开启 **开发人员模式**
4. 点击 **加载解压缩的扩展**，选择本项目根目录（包含 `manifest.json` 的文件夹）
5. 打开 [https://www.douyin.com](https://www.douyin.com) 并 **登录账号**

### 方式二：打包为 ZIP（用于上架或分发）

```powershell
.\scripts\package.ps1
```

打包结果默认输出到 `dist/` 目录。

## 使用说明

### 1. 拉黑当前作者

任选一种方式：

- 点击页面右下角 **「拉黑作者」** 悬浮按钮
- 点击浏览器工具栏中的扩展图标，在弹窗中点击 **拉黑当前作者**
- 使用快捷键 **`Ctrl + Shift + B`**

### 2. 解除拉黑

若当前作者已在黑名单中：

- 悬浮按钮会变为 **「解除拉黑」**
- 弹窗中会显示 **已拉黑** 标签及解除按钮
- 快捷键 **`Ctrl + Shift + U`**

### 3. 黑名单管理

可通过以下入口打开管理页：

- 扩展弹窗右上角 **「黑名单」**
- 扩展详情页 → **扩展选项**

管理页支持：

- 按昵称 / `sec_uid` 搜索
- **解除拉黑**（调用抖音接口并删除本地记录）
- **打开主页**（跳转作者抖音主页）
- **仅删记录**（只删除本地记录，不自动在抖音解除）
- **清空记录**（清空本地黑名单）

## 技术说明

### 作者识别

扩展通过多种方式识别当前视频作者：

- 正在播放的 `video` 元素及其父容器
- 页面中的用户主页链接（`/user/{sec_uid}`）
- 抖音接口返回数据缓存（拦截 `fetch` / `XHR` 响应）

### 拉黑实现

- 调用抖音网页端接口：`/aweme/v1/web/user/block/`
- 在页面上下文中注入脚本，复用抖音自身的签名机制（如 `_byted_acrawler`）
- 请求携带浏览器 Cookie，**需用户已登录抖音网页版**

### 数据存储

- 黑名单保存在浏览器本地：`chrome.storage.local`
- **不上传至任何开发者服务器**
- 详见 [隐私政策](docs/privacy-policy.zh-CN.md)

## 常见问题

**Q：提示「未识别到作者」？**  
A：请先确保视频正在播放，然后点击弹窗中的「刷新作者信息」，或刷新抖音页面后重试。

**Q：拉黑失败 / 403？**  
A：请确认已登录抖音网页版。若仍失败，刷新页面让签名脚本重新加载后再试。

**Q：「仅删记录」和「解除拉黑」有什么区别？**  
A：「仅删记录」只删除扩展本地保存的黑名单；「解除拉黑」会真正调用抖音接口取消拉黑。

**Q：快捷键不生效？**  
A：Chromium 扩展快捷键必须包含 `Ctrl` 或 `Alt`，不能单独使用 `Shift`。可在扩展管理页重新绑定。
